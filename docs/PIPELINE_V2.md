# 当前流程：三个目标、按方言分开

更新：本文件说明原双任务基线。最新网页默认 45 特征联合树（research），仍保留独立质量门槛；质量优先组合另作对照。完整新设计、实测消融和局限见 [ABLATIONS](../reports/ABLATIONS.md) 与 [新手指南](USER_GUIDE.md)。两种方言的隔离和来源保留规则不变。

## 1. 学习 Crum 的专业编纂风格

Crum 是风格学习的专业参照。此任务直接使用他在同一条目/构词段落内引用的先后关系，不把它和人工好坏标签强行合并成一串数值，也不把排序靠后的引用视为坏句子。

完整抽取先独立保留数字化目录中每一处 Bible 标记，再分别解释：书卷、整章、精确节、字母章节、titulus、subscriptio、多书卷缩写。每条包含原始字节/字符位置、原文、页码、词头、段落、编纂顺序、方言证据与 TLA 候选。

本次 41,808 处显式标记全部通过位置回读，包含旧流程没有输出的引用。这个完整性结论限定于当前数字化文本的显式标记；它不证明所有印刷本未标记引用都已被数字化作者发现，也不证明 41,808 处都能映射到本地某一个句子。

TLA 不唯一时保留歧义，不能静默取第一个。风格训练可使用方言和实际目标形式确定的唯一条目；若多个候选的 lemma/POS 完全一致，只用它们共有的局部特征学习文章顺序，并保留 TLA 未决状态。不能匹配目标形式的链接不会被当作正确训练句。

线性风格模型学习 `features(先例)-features(后例)`，保存原始严格次序；树排序对照使用组内全部等级，不把第 21 个以后的引用压成同一等级。单组最多抽 48 对训练关系，是控制训练量，不是丢弃原始引用或修改顺序。

## 2. 单句：好例句不只是命中目标词

用原始专家表学习“被选中/明确禁用”。没有 priority 的专家选中例仍是收录正例，但不被编造成 priority=1。空白未标注候选是 unknown，不作为负例。

当前 44 个特征包括 24 个 GDEX 启发表面特征、12 个原生依存特征、8 个目标上下文信息特征。新增目标修饰语、属性谓词、上下文实词、论元结构和多样性等，避免把信息量简单等同于句长。苹果示例只作依存结构回归测试，不伪称为 Coptic 人工评价。

质量模型和 Crum 风格模型分别训练、分别验证、分别选模型。两者可能对不同例句有偏好，这不是标签矛盾。当前组合初始权重：0.60 收录分数 + 0.20 Crum 风格百分位 + 0.15 信息量 + 0.05 义项词面支持；没有声称该权重已最优化。

C992/C998 的便宜候选阶段使用明确词面证据作保守过滤，不能解决所有同形词或译文改写。这个过滤会损失部分释义间接的好句，完整检索索引仍保留它们。

## 3. 三句集合：质量之外还要覆盖用法

先要求单句收录分数至少达到该候选池最高收录分数的一半，再从便宜模型高分池中保留组合分数下限，再选约十条兼顾句法覆盖的候选。单个集合始终只有一个 TLA 和一个方言。

句法签名围绕目标 token：主/宾/附属关系、上级词性、矩阵或从属结构、论元框架、修饰结构、局部助动词、否定。它们来自 TT 的自动/校验标注，不能自动视为人工 gold。

`cluster/` 比较：直接前三；二值句法特征 K-means 后各选高分句；在十条中穷举 120 个三元组合。集合目标 = 0.60 平均单句分数 + 0.30 自动句法覆盖 - 0.10 词汇重复。报告质量损失与覆盖收益，不只报告优化过的指标。

当前不调用大模型。候选包包含十条原文、译文、引用、模型分项和句法证据；下一步才让大模型选三条。本地三元组合是研究对照，不冒充大模型结果。

## 4. 方言是数据维度，不是界面标签

每个片段保留原语言字符串、规范化 dialect_id 和识别证据。当前配置 Sahidic / Bohairic；不认识的元数据进入 unknown，即便目录看起来像 Sahidic。元数据和目录冲突会记录。词典各个 form 的 geo 代码约束候选匹配；通用 TLA 可在不同方言有独立候选，但不混合展示或选择。

每个方言有独立词频、模型、验证、候选包。CV 按 lemma 划分并清除跨折相同 Coptic 片段。新方言通过配置登记，然后重建自己的统计与模型，不能暗中回退使用 Sahidic 模型。

示例（需由懂方言的人核对别名与代码后再启用）：

```toml
[dialects.new_dialect]
name = "New dialect"
codes = ["Z"]
aliases = ["New dialect Coptic"]
path_globs = ["new-corpus/*"]
```

## 5. 实验解释

线性与小型树模型共用固定五折作探索性模型选择，不是模型选择后的独立测试。Bohairic 只有极少人工正例/顺序对，其指标必须标为 provisional。不能与历史混合方言、不同候选与不同标签协议的数字直接比较。

当前不足仍包括 TLA 歧义、Coptic/英文 Bible 节号差异、译文对齐、少量未识别方言、人工偏好稀少。所有待核对项在引用/数据审计中保留。原始源文件保持不变。
