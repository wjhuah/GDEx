# 三条例句能否覆盖不同句法用法

本目录是独立的集合选择实验。单句质量由低成本模型先估计；随后比较三种办法：直接取前三、句法 K-means 后各组选最佳、在十条候选中穷举所有三元组合优化质量/句法覆盖/重复度。

句法特征围绕目标 token 提取：它是主语/宾语/介词附属等，所在矩阵/从属结构、谓词论元框架、修饰成分、局部助动词和否定。没有用整句长度代替句法多样性，也不以翻译 embedding 的主题距离冒充句法覆盖。

集合仅在同一个 `(TLA, dialect)` 内选择。自动依存标注的覆盖是可测代理指标，仍需人工核对；不能将“覆盖自动特征变多”宣称为“语言学上已经完整”。质量低的离群句不能仅因罕见结构被选入。

```bash
python scripts/train_shortlist.py
python cluster/evaluate.py
python run.py shortlist C998 --dialect sahidic
```

后续大模型只需看 `reports/shortlists/*/packet.json` 中的约十条候选及其引用、单句证据和句法说明。当前阶段没有调用大模型，也不会把本地三元组合实验伪称为大模型的最终选择。

方法依据：[Lin & Bilmes, ACL 2011](https://aclanthology.org/P11-1052/)。本实现是有明确权重的简单集合目标，并未声称复现论文或取得其理论最优保证。
