# Features

| Feature | Definition |
|---|---|
| `bound_group_len` | Whitespace-separated group count |
| `mean_log_word_frequency` | Mean log frequency of context content words |
| `pronoun_ratio` | Pronoun proportion |
| `n_subordinate_clauses` | Subordinate-clause count |
| `mean_dep_distance` | Mean dependency distance |
| `context_content_count` | Context content-word count, capped at 12 |
| `filled_argument_roles` | Distinct filled argument roles |
| `sense_cosine` | Definition–translation BGE cosine |
| `semantic_cache_missing` | Missing semantic-cache indicator |
| `sense_cosine_margin` | Cosine margin over competing entries |
| `sense_overlap` | Definition-word coverage in translation |
| `target_pos_match_ratio` | Target POS agreement ratio |
| `frame_probability` | Relative frequency of the target dependency frame |
| `collocation_log_mean` | Mean log frequency of dependency collocations |
| `target_position_ratio` | Relative target position |
